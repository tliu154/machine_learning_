## 05.3 特别说明（结合视觉组方向）

这是整套教程的**终点目标**，把已有 C++/OpenCV 经验和 ML 串起来：

```
采集/标注 → 数据集划分 → YOLO 训练 → mAP/速度评估
   → 导出 ONNX → C++ / OpenVINO 推理 → 上机测试
```

框架阶段先只建目录，实际做的时候再决定数据集规模、标注工具、部署平台。
注意 `.gitignore` 已排除数据集与权重文件，**不要把大文件提交进仓库**。

## 每个项目的固定交付物

1. `README.md`：目标、数据从哪来、怎么复现、结果指标
2. `src/` 或单个 `.py`：能从头跑通的脚本
3. `notes.md`：踩过的坑 + 为什么这么选（比代码更值钱）

> 项目不强制配 `exercises/`，但脚本要能自测（固定种子、小样本 smoke test）。
