# 01 数学基础

**目标：够用就好。** 不追求数学证明，只求能看懂损失函数、能自己推梯度下降。
所有公式都用 numpy 落地成代码，别停在纸面。

前置：00.2~00.4（numpy 数组、广播、矩阵乘 `@`）

## 练习设计方向

- 01.1：手写协方差矩阵、用 SVD 做 PCA 的前置、求解 `Ax=b`
- 01.2：抛硬币/骰子模拟 → 频率收敛到概率；最大似然估计均值
- 01.3：对 `y = ax + b` 手写梯度下降拟合，画损失曲线
- 01.4：手写交叉熵，验证预测越准损失越小
