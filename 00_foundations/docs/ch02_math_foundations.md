### 先记住这 5 个符号

全章只用到这 5 个，其余出现时当场解释（全仓库约定见 [NOTATION.md](../../NOTATION.md)）。

| 符号 | 读作 | 人话 |
|---|---|---|
| $x$ | 小写 x | 一个样本，通常是一串数（向量） |
| $X$ | 大写 X | 整张数据表，形状 $(n,d)$：$n$ 行样本、$d$ 列特征 |
| $\theta$ | theta | 所有待学参数的打包（$w$、$b$ 都装里面） |
| $L(\theta)$ | 损失 L | 一个**标量**：当前参数下模型错得有多离谱 |
| $\nabla_\theta L$ | 梯度 nabla L | 把 $L$ 对每个参数的偏导排成一列，指向**上坡最陡**方向 |

符号读音速记：$\nabla$ 读 nabla、$\partial$ 读偏、$\sum$ 读求和、$\eta$ 读 eta（学习率）、$\sigma$ 读 sigma。
**不用怕 $\nabla$**：它只是「把好几个偏导装进一个数组」，代码里就是 `grad = np.array([dw, db])`。

### 2.1 向量与矩阵（Vectors and Matrices）

**理论基础**

直觉：一张成绩表，每行一个学生、每列一门课。**向量 = 表里的一行，矩阵 = 整张表**，ML 里没有更玄的东西。

$$\mathbf{x}=(x_1,\dots,x_d),\qquad X\in\mathbb{R}^{n\times d},\qquad \|\mathbf{x}\|=\sqrt{\textstyle\sum_j x_j^2}$$

「$d$ 是特征数、$n$ 是样本数；$\mathbb{R}^{n\times d}$ 只表示「$n$ 行 $d$ 列的实数表」」。
最后那个 $\|\mathbf{x}\|$ 叫**长度**：各分量平方求和再开根，几何上就是箭头有多长。
**行 = 样本、列 = 特征**是 sklearn / PyTorch 共同约定。

**实际应用**

ML 代码第一件事永远是 `print(X.shape)`：形状错了不会编译报错，只会悄悄算错。

```python
import numpy as np
X = np.array([[1., 2.], [3., 4.], [5., 6.]])   # 3 个样本，2 个特征
print(X.shape)              # (3, 2)
print(X[0])                 # [1. 2.]      ← 第 0 个样本
print(X[:, 0])              # [1. 3. 5.]  ← 第 0 列特征
print(X.T.shape)            # (2, 3)       ← 转置：行列互换
w = np.array([2., -1.])
print(np.linalg.norm(w))    # 2.2360679... = sqrt(4 + 1)
```

长度在 ML 里的用处：Ridge 惩罚 $\|\theta\|^2$（[ch05](../../01_ml_framework/docs/ch05_error_sources.md)）、
KNN 用距离找邻居（[ch08](../../02_supervised/docs/ch08_classical_classifiers.md)）、
以图搜图比 embedding 相似度，本质都是长度和夹角。

**常见误区**：**`X[0]` 是一个样本，`X[:, 0]` 是一个特征**，别看反。
一维数组 `np.array([1,2,3])` 的 shape 是 `(3,)`，既不是行也不是列向量，喂 sklearn 前要 `reshape(-1, 1)`。

**够用边界**：会看 shape、取行列、算 `norm` 就够；行列式、逆矩阵不必学，
特征值等到 [第 12 章 12.1 PCA](../../03_unsupervised/docs/ch12_dimensionality.md#c12-01) 会用一句话讲清它在干什么。

**对应练习**：[第 1、2 题](../exercises/ch02_ex.py)

> 和 C++ 的差异：`std::vector<double>` 只有长度、没有行列；numpy 里形状是数据的一部分，
> `(3,2)` 和 `(2,3)` 是两个完全不同的东西。

### 2.2 矩阵乘法（Matrix Multiplication）

**理论基础**

直觉：**批量打分**。每个样本的一行特征，和一组「配方权重」逐项相乘再求和，得到一个分数；
矩阵乘法就是把 $n$ 个样本的分数**一次性全算出来**。

$$\hat{\mathbf{y}}=X\theta,\qquad (X\theta)_i=\sum_{j=1}^{d} X_{ij}\theta_j$$

「第 $i$ 个样本的预测 = 它第 $j$ 个特征乘第 $j$ 个权重，全部加起来」。
形状规则只有一条：**左矩阵的列数 = 右矩阵的行数**，结果取左的行数 × 右的列数，$(n,d)@(d,k)\to(n,k)$。

**实际应用**

这就是 [ch04](../../01_ml_framework/docs/ch04_training_steps.md) 的 `w * x + b`、
[ch07](../../02_supervised/docs/ch07_linear_models.md) 的 `A @ theta` 在算的东西。

```python
X = np.array([[1., 2.], [3., 4.], [5., 6.]])
w = np.array([2., -1.])
print(X @ w)          # [0. 2. 4.]   ← 3 个样本一次算完
print(X * w)          # [[ 2. -2.]   ← 注意！这是逐元素乘，不是矩阵乘
                      #  [ 6. -4.]
                      #  [10. -6.]]
A, B = np.ones((3, 2)), np.ones((2, 4))
print((A @ B).shape)  # (3, 4)，元素全为 2.0
```

`X @ w` 与逐行手算 `[0., 2., 4.]` 完全一致；广播规则复习见 [np02 广播](../data_stack/docs/np02_broadcast.md)。
转置 $X^\top$ 之所以在梯度里到处出现（`A.T @ (p - y) / n`），是为了把「每个样本的误差」按特征列汇总回去。

**常见误区**：**`*` 是逐元素乘（会广播），`@` 才是矩阵乘**。两者在 numpy 里都不报错，
结果形状却可能完全不同 —— 这是静默错误，只能靠 `print(shape)` 抓。

**够用边界**：会做维度匹配、看懂 `A.T @ err` 就够；矩阵求逆、SVD、正交性本章不需要。

**对应练习**：[第 3、4 题](../exercises/ch02_ex.py)

> 和 C++ 的差异：C++ 要手写三重 `for` 或调 BLAS；numpy 一个 `@` 搞定，但**代价是形状错了编译期不拦**。

### 2.3 概率分布（Probability Distribution）

**理论基础**

直觉：**一个按固定脾气吐数字的机器 + 一张它吐出来的直方图**。
「分布」描述的不是某一次的结果，而是「长期看，各个值出现得多频繁」。

$$\hat p=\frac{\#\text{正例}}{n},\qquad x\sim\mathcal{N}(\mu,\sigma^2)$$

「$\hat p$ 是用频率估出来的概率（样本越多越准）；$\mathcal{N}(\mu,\sigma^2)$ 是正态分布，
$\mu$ 是中心、$\sigma$ 是散布宽度」。**本章不需要你记密度函数**，知道「均值定中心、标准差定胖瘦」就行。

**实际应用**

数据里的噪声、参数随机初始化、train/val 划分，全靠分布和随机种子。

```python
rng = np.random.default_rng(42)          # 固定种子，结果可复现
noise = rng.normal(0, 0.05, 50)
print(round(noise.mean(), 6), round(noise.std(), 6))   # 0.004561 0.038028
print(round(noise.min(), 6), round(noise.max(), 6))    # -0.097552 0.107082
for n in (10, 100, 10000):
    print(n, rng.binomial(1, 0.17, n).mean())          # 0.0000 / 0.1100 / 0.1670
```

这正是 [ch04](../../01_ml_framework/docs/ch04_training_steps.md) 造数据的那行 `rng.normal(0, 0.05, 50)`：
真值 $3x+2$ 上叠加噪声，模型才需要「学」而不是「抄」。
`p=0.17` 的伯努利采样在 $n=10$ 时**一个正例都没抽到**，$n=10000$ 才稳到 $0.1670$ —— 频率收敛到概率。

**常见误区**：**小数目的频率不是概率**。$n=10$ 抽不到正例不代表 $p=0$；
另外不固定种子，每次跑出来数字都不同，实验就没法对照（全仓库统一 `default_rng(42)`）。

**够用边界**：会采样、会看频率、知道「噪声用正态分布」就够；密度函数、共轭先验、极限定理都不用碰。

**对应练习**：[第 5 题](../exercises/ch02_ex.py)

### 2.4 条件概率与贝叶斯（Conditional Probability and Bayes）

**理论基础**

直觉：**「已知一条消息后，把候选范围缩小」**。
$P(A\mid B)$ 读作「在 B 已经发生的前提下 A 的概率」，$\mid$ 后面的就是已知条件。

$$P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)}$$

「想从『得了病的人里有多少测出阳性』倒推『测出阳性的人里有多少真得病』，
就得乘回**得病的基础比例** $P(A)$ 再除以阳性总比例 $P(B)$」。
$P(A)$ 叫**先验**（没做检测前的比例），$P(A\mid B)$ 叫**后验**（拿到结果后更新的比例）。

**实际应用**

朴素贝叶斯（[ch08](../../02_supervised/docs/ch08_classical_classifiers.md)）、类别不平衡下的指标解读
（[ch06](../../01_ml_framework/docs/ch06_evaluation_metrics.md)）都卡在这里。实跑一个经典反直觉例子：

```python
prior, sens, fpr = 0.01, 0.99, 0.05      # 患病率 1%，敏感度 99%，误报率 5%
p_pos = sens * prior + fpr * (1 - prior)  # 0.059400
post = sens * prior / p_pos               # 0.166667
```

检测「准确率 99%」，**阳性的人里却只有 16.67% 真患病** —— 因为健康人基数太大，
$5\%$ 的误报造出大量假阳性。10 万人枚举实测：阳性 5975 人、其中真病 977 人，比例 `0.1635`
（与 `0.1667` 的差距是抽样波动，不是公式错）。

**常见误区**：**把 $P(\text{阳}\mid\text{病})$ 当成 $P(\text{病}\mid\text{阳})$**（基率谬误），
以及忘了先验 —— 类别极不平衡时，全预测负类也能拿 99% 准确率。

**够用边界**：会把四个量代进公式、知道先验不能丢就够；不用学概率空间、条件独立性证明。

**对应练习**：[第 6 题](../exercises/ch02_ex.py)

### 2.5 期望与方差（Expectation and Variance）

**理论基础**

直觉：把一组数撒在数轴上，**期望是重心，方差是散开程度**。

$$\mathbb{E}[x]=\frac{1}{n}\sum_{i=1}^{n}x_i,\qquad \mathrm{Var}(x)=\frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^2$$

「期望就是平均数；方差是『每个数离平均数多远』的平方再取平均；标准差 $\sigma=\sqrt{\mathrm{Var}}$ 把它换回原来的单位」。
用平方是为了不令正负偏差互相抵消。

**实际应用**

标准化（[ch10](../../02_supervised/docs/ch10_feature_engineering.md)）、
偏差—方差分解（[ch05](../../01_ml_framework/docs/ch05_error_sources.md)）、
MSE 损失（[ch06](../../01_ml_framework/docs/ch06_evaluation_metrics.md)）都是这两个量。

```python
a = np.array([2., 4., 4., 4., 5., 5., 7., 9.])
print(a.mean(), a.var(), a.var(ddof=1), a.std())
#            5.0     4.0      4.571429     2.0
for n in (10, 1000, 100000):
    s = np.random.default_rng(42).normal(3, 2, n)
    print(n, round(s.mean(), 4))    # 2.3289 / 2.9422 / 2.9915
```

`normal(3,2)` 的样本均值随 $n$ 增大逼近 3，这就是「用样本均值估计期望」为什么靠谱。

**常见误区**：**`np.var` 默认 `ddof=0`（除 $n$），教科书里的「样本方差」除 $n-1$**（本例 4.0 vs 4.571429）。
两者都没错，是「描述这批数据」和「估计总体」两种目的；报数字时说清用哪个。
另外标准差 2.0 ≠ 平均绝对偏差，别当成「平均差了 2」。

**够用边界**：会 `mean` / `var` / `std`、知道 `ddof` 存在就够；协方差、矩估计、大数定律证明都不需要。

**对应练习**：[第 7 题](../exercises/ch02_ex.py)

### 2.6 导数与偏导（Derivative and Partial Derivative）

**理论基础**

直觉：**「这一点上，自变量动一小步，因变量跟着动多少倍」**，也就是斜率 / 灵敏度。
偏导就是「有好几个旋钮时，只拧其中一个，其余按住不动」。

$$f'(x)\approx\frac{f(x+\varepsilon)-f(x-\varepsilon)}{2\varepsilon}$$

「在 $x$ 左右各取一小步，看函数值差多少，再除以步长的两倍」—— 这叫**中心差分**。
**你完全不用会手推求导法则**：只要能算函数值，就能用这一行数出导数。

**实际应用**

梯度下降里所有 `dw` / `db` 都是这个东西；数值梯度检验
（[ch04 4.3 节](../../01_ml_framework/docs/ch04_training_steps.md#c04-03)）也用它验解析梯度。

```python
def numerical_derivative(f, x, eps=1e-6):
    return (f(x + eps) - f(x - eps)) / (2 * eps)

print(numerical_derivative(lambda x: x ** 2, 3.0))    # 6.0000000008（解析解 6）
g = lambda w, b: (w * 2 + b - 5) ** 2
# 只动 w、按住 b：dw = -8.0000000005；只动 b、按住 w：db = -4.0000000006
```

$x^2$ 在 $x=3$ 解析导数是 6，中心差分给 `6.0000000008`；
$g(w,b)=(2w+b-5)^2$ 在 $(1,1)$ 处的两个偏导，数值解与解析的 $-8$、$-4$ 吻合到 $10^{-9}$。

**常见误区**：**`eps` 不是越小越好**。太小会撞上浮点精度（两个相近数相减丢有效位），
太大又不再是「局部」斜率；`1e-6` 对 float64 通常是安全区。另外单边差分 `(f(x+eps)-f(x))/eps`
精度比中心差分低一阶，别混用。

**够用边界**：会写中心差分、能看懂「偏导 = 只动一个参数」就够；求导法则、泰勒展开不用记。

**对应练习**：[第 8、9 题](../exercises/ch02_ex.py)

> 和 C++ 的差异：C++ 里没有自动求导，你得自己写差分或手推解析式；
> 后面 PyTorch 的 autograd 只是把这个差分/链式过程自动化了（第 14 章）。

### 2.7 梯度（Gradient）

**理论基础**

直觉：站在山坡上，**梯度指「上坡最陡的那个方向」**，那**负梯度**自然就是下坡最陡的方向。
把 2.6 里每个参数的偏导排成一列，就是梯度。

$$\nabla_\theta L=\left(\frac{\partial L}{\partial\theta_1},\dots,\frac{\partial L}{\partial\theta_m}\right),\qquad
\theta\leftarrow\theta-\eta\nabla_\theta L$$

「左边是把 $m$ 个偏导打包成向量；右边是训练时反复做的那一步：沿负梯度走一小步」。
$\eta$（学习率）控制迈多大步。**所以是减号**，加号是在往损失更大的方向爬。

**实际应用**

用 [ch04](../../01_ml_framework/docs/ch04_training_steps.md) 同一份数据（$y=3x+2+$ 噪声，$w=b=0$ 起步，$\eta=0.1$）：

```python
theta = np.zeros(2)
g = np.array([-4.02889222, -7.0091211])   # ∇L(0,0)，由 ch04 的 mse_gradients 实跑得到
print(theta - 0.1 * g)                    # [0.40288922 0.70091211] ← 一步更新
```

起点 $L(0,0)=13.075774$、$\|\nabla L\|=8.084538$。
**固定步长 0.1**、沿不同单位方向各走一步，实跑结果（练习第 11 题让你自己复现）：

| 走的方向 | 走完的 L | 变化 |
|---|---|---|
| $-\nabla L$（负梯度） | 12.279993 | **−0.795780** ← 降最多 |
| 45° 斜着走 | 12.306959 | −0.768814 |
| 只动 b | 12.384861 | −0.690912 |
| 只动 w | 12.676252 | −0.399522 |
| $+\nabla L$（正梯度） | 13.896901 | +0.821127 ← 反而上升 |

负梯度方向确实降得最多，这就是「最陡下坡」的实测证据。
按更新式走一步到 $(0.4029, 0.7009)$，$L$ 从 `13.0758` 掉到 `7.3681`；
反复 200 轮后 $w=2.9261$、$b=2.0451$、$L=0.002222$，逼近真值 $3$ 和 $2$。

**常见误区**：**$\eta$ 不是走的距离，实际走的是 $\eta\|\nabla_\theta L\|$**（本例 $0.1\times8.08\approx0.81$）。
所以梯度很大时哪怕学习率很小也可能一步跨过头、损失变 `inf`。
另一个坑：梯度为 0 只说明「平地」，可能是局部极小或鞍点，不保证是全局最优。

**够用边界**：懂「梯度是上坡、要减」、会看 `grad.shape` 与参数对齐就够；凸性、Hessian、动量不用碰。

**对应练习**：[第 10、11 题](../exercises/ch02_ex.py)

### 2.8 链式法则（Chain Rule）

**理论基础**

直觉：**齿轮传动 / 一串多米诺**。$w$ 变了 → 预测 $\hat y$ 变了 → 损失 $L$ 变了；
总的影响等于**每一级影响相乘**。

$$\frac{dL}{dw}=\frac{dL}{d\hat y}\cdot\frac{d\hat y}{dw}$$

「『$L$ 对 $w$ 的导数』=『$L$ 对 $\hat y$ 的导数』乘『$\hat y$ 对 $w$ 的导数』」。
中间量 $\hat y$ 就像传动轴，把两头接起来；层数再多也只是**继续往左乘**。

**实际应用**

反向传播（第 14 章）从头到尾只是在对计算图重复这一条。单样本 $L=(y-(wx+b))^2$，
取 $x=2,y=5,w=1,b=1$（于是 $\hat y=3$、误差 $=2$）：

```python
err, x = 2.0, 2.0
dL_dyhat = -2 * err          # -4
dyhat_dw = x                 #  2
print(dL_dyhat * dyhat_dw)   # -8.0  ← 链式法则
# 直接对 w 做中心差分：-8.0000000005；直接展开 -2*err*x：-8.0
```

三种算法给出同一个 $-8$，说明链式分解没算错。
顺带一个后面会反复出现的数值：`sigmoid(0.5)=0.622459`，其导数
$\sigma(1-\sigma)=0.235004$，与中心差分 `0.235004` 一致。

**常见误区**：**是相乘，不是相加**，而且**一层都不能漏**。
连乘多个小于 1 的数会迅速趋近 0 —— Sigmoid 导数最大也只有 0.25，
深层网络里连乘几十次就是**梯度消失**（第 15 章），换成 ReLU 正是为了绕开它。

**够用边界**：会「拆中间量 → 逐段求导 → 相乘」就够；多元链式法则的矩阵形式（Jacobian）本章不讲。

**对应练习**：[第 12 题](../exercises/ch02_ex.py)

## 小结：数学在 ML 中的位置

原骨架里的「2.4 数学在 ML 中的位置」不单独占一节，压缩成这张**随查表** —— 碰到哪一章卡住，就回到对应小节。

| 数学 | 在 ML 里变成 | 出现在 |
|---|---|---|
| 向量 / 矩阵 / 长度 | 数据表 `X`、参数 `theta`、正则项、样本距离 | 全仓库；[ch08](../../02_supervised/docs/ch08_classical_classifiers.md)、[ch05](../../01_ml_framework/docs/ch05_error_sources.md) |
| 矩阵乘法 / 转置 | 一次前向 `X @ theta`、梯度汇总 `A.T @ err` | [ch04](../../01_ml_framework/docs/ch04_training_steps.md)、[ch07](../../02_supervised/docs/ch07_linear_models.md) |
| 概率 / 条件概率 / 期望方差 | 噪声、朴素贝叶斯、标准化、偏差—方差、各类指标 | [ch08](../../02_supervised/docs/ch08_classical_classifiers.md)、[ch10](../../02_supervised/docs/ch10_feature_engineering.md)、[ch06](../../01_ml_framework/docs/ch06_evaluation_metrics.md) |
| 导数 / 梯度 / 链式法则 | `w -= lr * dw`、反向传播、梯度消失 | [ch04](../../01_ml_framework/docs/ch04_training_steps.md)、第 14~15 章 |

| C++ / 已有认知 | 本章写法 |
|---|---|
| `std::vector<double>` 只有长度 | 形状 `(n,d)` 是数据的一部分，行=样本 |
| 三重循环做矩阵乘 | 一个 `@`，但形状错不报错 |
| `rand()` / `<random>` 要手动配 engine | `default_rng(42)` 一行固定种子 |
| 手推导数或手写差分 | 中心差分一行；框架给 autograd |

> **最容易踩的 3 个坑**：
> 1. `*` 和 `@` 混用 —— 形状可能完全不同却不报错
> 2. 把 $P(B\mid A)$ 当 $P(A\mid B)$，忘掉先验
> 3. 以为学习率 $\eta$ 就是步长 —— 实际走的是 $\eta\|\nabla_\theta L\|$，梯度大时容易发散
>
> **够用判据**：能看懂 `loss = np.mean((y - X @ theta) ** 2)`，
> 能自己写出 `theta -= lr * grad`，这一章就可以放下了。
