### 全章共用的实验装置：一个 8 层 MLP

为了让「深」这件事真的发生，本章所有数字都来自同一套装置：输入 64 个样本、
每层 32 个神经元、堆 8 层，权重按指定标准差从正态分布采样，偏置为 0，固定 `seed=0`。

```python
import numpy as np

def build(act, std, d=32, L=8, n=64, seed=0):
    rng = np.random.default_rng(seed)
    X = rng.standard_normal((n, d))
    W = [rng.normal(0, std, (d, d)) for _ in range(L)]
    return X, W

def forward(X, W, act):
    A, stats = X, []
    for w in W:
        Z = A @ w
        A = act(Z)
        stats.append(float(A.std()))   # 每层激活值的标准差
    return A, stats
```

**怎么看梯度**：把最上层的梯度人为设成 1 这个量级（排除损失本身的影响），
然后按 [ch14 的反向传播](ch14_nn_basics.md#c14-04) 一层层往回乘，
记录每一层输入侧梯度的**范数** —— 就是「这串数整体有多长」，
[ch02 2.1](../../00_foundations/docs/ch02_math_foundations.md#c02-01) 讲向量长度时算过。
**首层梯度 ÷ 末层梯度** 越接近 1，说明信号传得越完整。

### 先看结论：8 层网络上的实测

| 配置 | 首层梯度范数 | 末层梯度范数 | 8 层后激活 std | 结论 |
|---|---|---|---|---|
| Sigmoid，`std=1.0` | `3.296e-02` | `6.665e-01` | `0.3885` | 首层只剩末层的 **1/30** |
| ReLU，`std=0.1`（太小） | `1.677e-03` | `4.272e-01` | `0.0007` | 差 **596 倍**，激活也快没了 |
| ReLU，`std=1.0`（太大） | `1.677e+05` | `4.272e+00` | `73755.8165` | **放大约 4 万倍**，数值爆炸 |
| ReLU，`std=2.0` | `4.292e+07` | `8.543e+00` | `1.89e+07` | 彻底炸穿 |
| **ReLU，He `sqrt(2/32)`** | **`2.558e+00`** | **`1.068e+00`** | **`1.1254`** | **基本保持（约 2.4 倍）** |
| tanh，Xavier `sqrt(1/32)` | `1.531e-01` | `8.296e-01` | `0.2683` | 差 6.5 倍，浅网络够用 |

> 这张表就是本章的骨架：**同样 8 层，只改权重初值的标准差，
> 梯度能衰减近 600 倍，也能放大 4 万倍**。初始化不是玄学调参，是数量级问题。

### 15.1 激活函数族（Activation Functions）

**概念定义**：激活函数是加在每个线性层后面的那个「逐元素小函数」。
[ch14 14.2](ch14_nn_basics.md#c14-02) 已经实测过：不加它，堆多少层都等于一层线性
（最大差 `1.11e-16`）。所以它的第一职责是**提供非线性**；第二职责才是本章的重点 ——
**它在反向传播里贡献的那个导数，决定梯度会不会被连乘压没**。

**数学形式**：只看导数，不用记原式推导。下表 $z$ 是这一层加权和（读作「z」，
就是「激活前的值」），$\sigma'(z)$ 读作「sigma 对 z 的导数」，人话就是「输入动一点，输出动多少」。

| 激活 | 式子 | 导数取值 | 人话 |
|---|---|---|---|
| Sigmoid | $\sigma(z)=1/(1+e^{-z})$ | $\sigma(1-\sigma)$，最大 **0.25** | 输出压进 (0,1)，但**天生把信号打 2.5 折** |
| tanh | $\tanh(z)$ | $1-a^2$，最大 **1** | 零中心版 Sigmoid，隐藏层比 Sigmoid 好 |
| ReLU | $\max(0,z)$ | **0 或 1** | 正半轴导数恒 1，连乘 8 次还是 1 |
| Leaky ReLU | $z>0?\ z:0.01z$ | **0.01 或 1** | 负半轴留条缝，专治死神经元 |
| GELU | $0.5z(1+\tanh(\sqrt{2/\pi}(z+0.044715z^3)))$ | 约 `-0.129 ~ 1.129` | 平滑版 ReLU，Transformer 里常用 |

**最小代码**：数值稳定的写法 + 把上表的上界亲手算出来。

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-np.clip(z, -60, 60)))   # clip 防 exp 溢出

def sigmoid_grad(z):
    s = sigmoid(z)
    return s * (1 - s)

def relu(z):       return np.maximum(0, z)
def leaky(z, a=0.01): return np.where(z > 0, z, a * z)
def gelu(z):
    return 0.5 * z * (1 + np.tanh(np.sqrt(2 / np.pi) * (z + 0.044715 * z ** 3)))

z = np.linspace(-20, 20, 400001)
print(sigmoid_grad(z).max())        # 0.25，在 z=0 处取到
print((1 - np.tanh(z) ** 2).max())  # 1.0
print(np.unique((z > 0).astype(float)))   # [0. 1.]
```

**饱和**：Sigmoid 输入一大就「躺平」了 —— `sigmoid(10)=0.99995460`，导数只剩
`0.0000453958`；`sigmoid(0)=0.5` 时导数才有 `0.25`。
所以 Sigmoid 的最好情况也就是每层乘 0.25，8 层就是 $0.25^8=$ `1.53e-05`，
16 层 `2.33e-10`。这正是 [ch02 2.8 结尾](../../00_foundations/docs/ch02_math_foundations.md#c02-08)
留的那句「连乘几十次就是梯度消失」，本章把它实测出来。

**常见误区**：**别把 Sigmoid 当隐藏层默认激活**。
它的输出均值是 0.5（不是 0），导数上界又只有 0.25，两个缺点叠在一起，
深层几乎必然梯度消失；它现在的正经岗位是**输出层做二分类概率**（[ch07](../../02_supervised/docs/ch07_linear_models.md)），
或者门控结构里当开关。

> 够用边界：会写这几个函数、知道「导数上界 0.25 / 1 / 1」这三个数就够；
> GELU 的完整式子不用背（记「平滑 ReLU」即可），它的数值梯度上界 `1.129` 是实测值，别当解析结论。
> 顺带一个实测：`x*sigmoid(1.702x)` 这个常见近似与精确 GELU 最大差 `0.0207`，要求严就别用近似。

**对应练习**：[`ch15_ex.py` 第 1~5 题](../exercises/ch15_ex.py)

> 和 C++ / 已有认知的差异：C++ 里你会写 `if (z > 0) return z; else return 0;`，
> numpy 里 `np.maximum(0, z)` 一次算完整个张量；**分支没了，但 `z=0` 那点的导数得自己定**
> —— 框架通常约定为 0，这是实现选择，不是数学结论。

### 15.2 梯度消失与梯度爆炸（Vanishing / Exploding Gradients）

**概念定义**：[ch14 14.4](ch14_nn_basics.md#c14-04) 的反向传播是一串连乘：

$$\frac{\partial L}{\partial z_1} = \underbrace{W_2^{\top}\sigma'(z_2)}_{\text{第 2 层}} \cdots \underbrace{W_L^{\top}\sigma'(z_L)}_{\text{第 L 层}} \frac{\partial L}{\partial z_L}$$

念作「损失对第 1 层输入的导数，等于后面每一层的（权重转置 × 激活导数）依次相乘，
再乘最上层的导数」。**每一项小于 1，连乘就趋近 0（梯度消失）；
大于 1，连乘就趋近无穷（梯度爆炸）**。这就是全章唯一需要懂的数学。

**最小代码**：把 8 层的前向缓存下来，再倒着乘回去，记录每层梯度范数。

```python
def deep_grad_norms(X, W, act, local_grad, d=32, n=64):
    A, Zs = X, []
    for w in W:
        Z = A @ w
        Zs.append(Z)
        A = act(Z)
    dA = np.ones_like(A) / np.sqrt(n * d)   # 上游梯度归一到 1
    norms = []
    for l in reversed(range(len(W))):
        dZ = dA * local_grad(Zs[l])         # 逐元素乘激活导数
        dA = dZ @ W[l].T                    # 乘权重转置，传回上一层
        norms.append(float(np.linalg.norm(dA)))
    return norms[::-1]                      # 按 第1层 → 第8层 排好
```

拿它跑本章那套装置（`d=32, L=8, n=64, seed=0`），结果（科学计数法，`e+05` 表示 ×10⁵）：

| 配置 | 第 1 层 → 第 8 层梯度范数（节选） | 首层 / 末层 |
|---|---|---|
| Sigmoid `std=1.0` | `3.296e-02 → 6.665e-01` | 衰减 **30 倍** |
| ReLU `std=0.1` | `1.677e-03 → 4.272e-01`，激活 std `0.3292 → 0.0007` | 衰减 **596 倍** |
| ReLU `std=1.0` | `1.677e+05 → 4.272e+00`，激活 std `3.29 → 73755.82` | **放大约 4 万倍** |
| ReLU `std=2.0` | `4.292e+07 → 8.543e+00` | 放大约 500 万倍 |
| **ReLU He** | `2.558e+00 → 1.068e+00`，激活 std `0.8231 → 1.1254` | **仅差 2.4 倍** |

注意 `std=0.1` 和 `std=1.0` 两行数字**一模一样只差 10⁸ 倍** —— 这不是巧合：
线性区里 ReLU 的导数恒为 1，整个网络就是 8 个矩阵连乘，
权重整体缩放 $c$ 倍，8 层后就是 $c^8$ 倍（$10^8$）。**深层网络对初值尺度是指数级敏感的**。

**死 ReLU**：ReLU 负半轴导数恒 0，一旦某神经元对所有样本都输出 0，它的梯度永远是 0，
参数再也不会更新 —— 叫「死神经元」。实测把偏置当成被一次过大更新推负：

| 偏置 | 第 1~8 层「全样本恒 ≤ 0」神经元比例 | 末层梯度范数 |
|---|---|---|
| `0.0`（正常 He） | `0.00 0.00 0.00 0.125 0.00 0.094 0.031 0.156` | `1.068e+00` |
| `-0.5` | 第 7、8 层已达 **1.000** | **`0.000e+00`** |
| `-1.0` | 第 4 层起全 1.000 | `0.000e+00` |
| `-5.0` | 8 层全 1.000 | `0.000e+00` |

也就是说，**仅一次大学习率更新把偏置推到 -0.5，后两层就集体死亡，梯度直接归零**。
这解释了为什么 [ch14 14.5](ch14_nn_basics.md#c14-05) 里 `lr=10` 会发散、
以及为什么 Leaky ReLU 要留 `0.01` 那条缝（负半轴导数不为 0，还有救回来的可能）。

**常见误区**：**梯度消失 ≠ 损失不降**。
浅层参数拿不到梯度，但靠近输出的几层照样在学，loss 会缓慢下降，
于是你以为「模型在收敛」，其实前面几层几乎是随机初始值。
判断方法不是盯着 loss，而是**打印逐层梯度范数** —— 这正是本节代码在做的事。

> 够用边界：会「打印每层梯度范数、看首末比是不是差了几个数量级」就够；
> 梯度裁剪、残差连接、归一化这些修法属于 [ch16](ch16_training_dnn.md)，本章只负责把病测出来。

### 15.3 权重初始化（Weight Initialization）

**概念定义**：初始化就是给权重矩阵定初值的**标准差**。
目标是让每一层的激活值标准差别逐层缩小到 0、也别放大到溢出 ——
上一节的表格已经证明这件事直接决定梯度量级。两个词先记住：
`fan_in` 读作「扇入」，指这一层**接收多少个输入**；`fan_out` 是**输出多少个**，
对全连接层就是权重矩阵的行数和列数。

**数学形式**：两条经验公式，**不用推，直接用**：

$$\text{Xavier: } \sigma=\sqrt{\frac{2}{\text{fan\_in}+\text{fan\_out}}}\qquad
\text{He: } \sigma=\sqrt{\frac{2}{\text{fan\_in}}}$$

人话：输入越多，每个权重就该越小，免得加权和越加越大。
Xavier 配 **tanh / Sigmoid**（导数上界 ≤1），He 配 **ReLU 家族** ——
因为 ReLU 会把大约一半神经元截成 0，等于丢了一半方差，所以要额外乘个 2 补回来。
等宽网络（fan_in = fan_out = 32）时 Xavier 退化成 $\sqrt{1/32}\approx0.177$，
He 是 $\sqrt{2/32}=0.25$。

**最小代码**：

```python
def init_scale(method, fan_in, fan_out):
    if method == "xavier":
        return np.sqrt(2 / (fan_in + fan_out))
    if method == "he":
        return np.sqrt(2 / fan_in)
    raise ValueError(method)

def init_weights(d, L, method, seed=0):
    rng = np.random.default_rng(seed)
    s = init_scale(method, d, d)
    return [rng.normal(0, s, (d, d)) for _ in range(L)]

for m in ["xavier", "he"]:
    print(m, round(init_scale(m, 32, 32), 6))
# xavier 0.176777   he 0.25
```

把不同初值塞进同一个 8 层 ReLU 网络，**前向激活 std** 的实测对比：

| 初值 | 第 1 层 → 第 8 层激活 std | 8 层后梯度首/末比 |
|---|---|---|
| `std=0.1`（naive 太小） | `0.3292 → 0.0007` | 衰减 596 倍 |
| `std=1.0`（naive 太大） | `3.2923 → 73755.8165` | 放大约 4 万倍 |
| **He `0.25`** | **`0.8231 → 1.1254`** | **仅 2.4 倍** |

He 那行两层数字都在 1 附近，说明**信号既没被压扁也没被吹爆**。
对照一下 tanh + Xavier：激活 std `0.6288 → 0.2683`（还是在缩，但 8 层只差 6.5 倍），
梯度 `1.531e-01 → 8.296e-01` —— 浅网络完全够用，超深网络才需要更进一步的手段。

**一个反直觉的实测**：Sigmoid 配 Xavier 反而**更糟** —— 首层梯度 `4.472e-06`，
比 `std=1.0` 的 `3.296e-02` 还小 4 个数量级（首/末差 `2.24e+05` 倍）。
原因是 Xavier 的方差推导假设激活零中心，而 Sigmoid 输出恒在 (0,1)、均值 0.5，
这个偏移会逐层累积。**公式不是万能的，得和激活函数配对用**。

**常见误区**：**别把「全零初始化」当成省事的默认值**。
所有权重给 0，同一层每个神经元拿到完全一样的输入和完全一样的梯度，
永远学到同一个东西（对称性问题）；给偏置全 0 倒是没关系，本章所有实验都这么做。

> 够用边界：会按激活函数选 `xavier`（tanh）还是 `he`（ReLU）、会算那两个根号就够；
> 正交初始化、fixup、μParam 这类进阶方案不在本教程范围。
> 顺带：用了 BatchNorm 之后初始化会宽容很多，那是 [ch16](ch16_training_dnn.md) 的事。

### 15.4 实操清单：把 ch14 的 `h=3` 悬念了结

**概念定义**：[ch14 14.5](ch14_nn_basics.md#c14-05) 留了个怪事 ——
隐藏层宽度 `h=1/2/3/4/8` 的验证准确率是
`0.6500 / 0.8250 / 0.7500 / 1.0000 / 1.0000`，`h=3` 反而比 `h=2` 差，
当时标成「局部最优，ch15 初始化来解决」。现在可以给出**诚实的答案**了。

用 [ch14 同一份 XOR 数据](ch14_nn_basics.md#c14-05)（160 样本、120 训练 / 40 验证），
`tanh` 隐藏层、`lr=0.5`、10000 步全批量梯度下降，跑 20 个随机种子：

| 初始化 scale | 20 种子中 val ≥ 0.95 的比例 | 平均 val | 最差 |
|---|---|---|---|
| naive `0.1` | **0.60** | `0.9262` | `0.8250` |
| ch14 原用 `0.5` | **0.40** | `0.9237` | `0.7500` |
| Xavier `sqrt(2/(2+3))` | **0.45** | `0.9375` | `0.8750` |
| naive `1.0` | 0.45 | `0.9400` | `0.9000` |
| naive `2.0` | 0.45 | `0.9263` | `0.7250` |

单看 `seed=0`，初始化确实「救」了这一把：

| scale | val acc | loss：第 0 步 → 第 10000 步 |
|---|---|---|
| `0.5`（ch14） | `0.7500` | `0.693544 → 0.372358`（卡住） |
| `0.1` | **`1.0000`** | `0.693104 → 0.091216` |
| Xavier | `0.9000` | `0.695114 → 0.110962` |

**但 20 个种子的整体成功率没有稳定提升**（最好也只有 0.60），
而把宽度从 `h=3` 加到 `h=4`，用 ch14 原来的 `0.5` 就有 **0.90** 成功率、均值 `0.9812`。

结论得说清楚，别糊弄：

- **初始化解决的是「梯度能不能传到底」**，那是 8 层、80 层的问题；
  2 层网络压根没有梯度消失，换初值只是在换**优化起点**，撞不撞上好的局部最优看运气。
- `h=3` 的主要瓶颈是**容量不足 + 局部最优**，不是梯度消失。
  系统性的解法是容量、优化器（Momentum / Adam）、学习率调度 —— 都在 [ch16](ch16_training_dnn.md)。
- 所以别信「换个 He 初始化模型就稳了」这种话。**先量出问题在哪一层，再选工具**。

**选型清单**（遇到新网络照着走，不用背公式）：

1. 隐藏层默认 **ReLU + He**；输出层按任务定（二分类 Sigmoid、多分类 Softmax、回归不加激活）
2. 用了 tanh / Sigmoid 隐藏层 → 换 **Xavier**，并优先怀疑「是不是该换 ReLU」
3. 训练前打印一次**逐层激活 std 和梯度范数**：
   差 3 个数量级以上就是有病，别等 loss 不降才回头查
4. 出现大量恒 0 神经元 → 试 **Leaky ReLU**，同时检查学习率是不是过大
5. loss 在降但浅层参数几乎不动 → 是梯度消失，不是「还没收敛」，本章第 2 节的量法直接复用
6. 只剩 2 层的小网络别在初始化上折腾，**加宽 / 换优化器**收益更大（上表已证）

**常见误区**：**别把「初始化」当成万能调参旋钮**。
上面 20 个种子的表就是反例：同一个网络，换 5 种初值，成功率都在 0.40~0.60 徘徊。
初始化是**让训练有可能正常开始**的地基，不是提升上限的捷径。

**和实践终点的联系**：以图搜图（见 [第 7 篇实践轨道](../../06_engineering/README.md)）
用的是**预训练模型抽 embedding**，不需要你从零初始化一个大模型 ——
但本章的知识仍然有用：拿到 embedding 后接的那几层小网络要自己初始化，
而且**预训练权重本身就是一次「好初始化」**，微调时学习率要小，
正是 [ch05 分布漂移](../../01_ml_framework/docs/ch05_error_sources.md) 和本章共同解释的事。
另外 [ch12 12.4](../../03_unsupervised/docs/ch12_dimensionality.md#c12-04) 说过
「加非线性激活才能学到 PCA 之外的表示」，这里补上了后半句：**加了激活，还得配对的初始化**。

**对应练习**：[`ch15_ex.py` 第 12 题](../exercises/ch15_ex.py)

## 小结

| [ch04 三步骤](../../01_ml_framework/docs/ch04_training_steps.md) | 本章对应 |
|---|---|
| 模型 $f_\theta$ | 8 层「线性 → 激活」堆叠；激活决定非线性，初值决定信号尺度 |
| 损失 $L$ | 本章不换损失，只观察**梯度怎么从损失回传** |
| 优化 | 初值不在优化器里，却直接决定优化器拿到的是 `1e-6` 还是 `1e+7` |

| C++ / 已有认知 | 本章写法 |
|---|---|
| `std::mt19937` 配个固定 scale 凭感觉 | `init_scale("he", fan_in, fan_out)`，跟激活函数绑定 |
| 数值溢出会变成 `inf` 一路传下去 | 先看激活 std，8 层能到 `1.89e+07`，早发现早收手 |
| 死代码可以静态检查出来 | 死 ReLU 是**运行时**才出现的，只能靠梯度统计抓 |

> **最容易踩的 3 个坑**：
> 1. **Sigmoid 当隐藏层默认激活** —— 导数上界 0.25，8 层就 `1.53e-05`，
>    [ch02 2.8](../../00_foundations/docs/ch02_math_foundations.md#c02-08) 早就预警过
> 2. **只盯 loss 不看逐层梯度** —— loss 在降也可能只有最后两层在学
> 3. **浅网络怪初始化** —— `h=3` 的 20 种子实测告诉我们，那时候该加宽或换优化器

**一句话带走**：深层网络的训练，一半是「激活函数的导数别连乘没」，
另一半是「初值的尺度别连乘炸」；而网络只有两层时，这两件事都不是主要矛盾。
