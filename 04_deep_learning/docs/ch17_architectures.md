### 17.1 卷积神经网络（CNN）

**概念定义**：卷积层拿一个小窗口（比如 $3\times3$）在图上滑动，每个位置做「窗口内的值加权求和」。
和全连接层相比它只押两个假设：**局部性**（相邻像素才相关）和**平移等变**（同一模式出现在哪都算同一个特征）。
这两个假设让参数从「每个像素一个权重」降到「一个卷积核到处复用」。

**数学形式**

$$\text{输出尺寸}=\left\lfloor\frac{H-k+2p}{s}\right\rfloor+1,\qquad
\text{参数量}=C_{out}\times C_{in}\times k\times k + C_{out}$$

$$\text{感受野（L 层 }3\times3\text{, }s=1\text{）}=2L+1$$

$k$ 是核大小、$p$ 是填充、$s$ 是步长。感受野就是「输出上一个点，能看见输入多大一块」。

**最小代码**

```python
def conv2d_naive(x, w, b, stride=1, pad=0):
    """x: (C_in,H,W)   w: (C_out,C_in,k,k)   b: (C_out,)"""
    if pad:
        x = np.pad(x, ((0, 0), (pad, pad), (pad, pad)))
    C_in, H, W = x.shape
    C_out, _, k, _ = w.shape
    Ho = (H - k) // stride + 1
    Wo = (W - k) // stride + 1
    out = np.zeros((C_out, Ho, Wo))
    for co in range(C_out):
        for i in range(Ho):
            for j in range(Wo):
                patch = x[:, i*stride:i*stride+k, j*stride:j*stride+k]
                out[co, i, j] = np.sum(patch * w[co]) + b[co]
    return out
```

**实测：手写版和 PyTorch 完全一致**

`C_in=3, C_out=5, k=3, p=1, s=1`，输入 $9\times9$：输出形状都是 `(5, 9, 9)`，
**最大绝对差 `7.105e-15`**。卷积没有任何黑魔法，`torch.nn.Conv2d` 只是把它写快了。

| 输入 | $k$ | $s$ | $p$ | 输出 |
|---|---|---|---|---|
| 32 | 3 | 1 | 1 | **32**（same padding） |
| 32 | 3 | 2 | 1 | **16**（尺寸减半） |
| 224 | 7 | 2 | 3 | **112**（ResNet 首层） |
| 64 | 5 | 1 | 0 | **60**（valid） |

第一行和第二行就是「为什么 CNN 越深图越小」：一次 `s=2` 就把分辨率砍一半。

**实测：钱花在哪**

| 层 | 参数量 |
|---|---|
| 3×3 conv，3→5 | `140` |
| 3×3 conv，256→256 | **`590,080`** |
| 1×1 conv，256→256 | `65,792` |
| 3×3 **depthwise** 256 | `2,560` |
| 全连接 256→256 | `65,792` |

两个直接结论：
- **卷积核大小是平方级的开销**。同样通道数，3×3 是 1×1 的 **9 倍**。
- **深度可分离卷积**（depthwise + 1×1 投影）把 3×3 那层从 `590,080` 压到 `2,560 + 65,792`，
  约 **1/8.6**。这是 MobileNet 系列能在手机上跑的原因。

**附：检测里必考的两个函数**

```python
def iou(a, b):                      # a,b = [x1,y1,x2,y2]
    x1, y1 = max(a[0], b[0]), max(a[1], b[1])
    x2, y2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    area = lambda z: (z[2] - z[0]) * (z[3] - z[1])
    return inter / (area(a) + area(b) - inter + 1e-12)
```

NMS 就是「按分数从高到低取框，把跟它 IoU 超阈值的都删掉，重复」。实测同一组 5 个框：

| 阈值 | 保留的框 |
|---|---|
| `0.3` / `0.5` | `[0, 4]` |
| `0.7` | `[0, 4, 2]` |
| `0.9` | `[0, 4, 1, 2, 3]`（一个没删） |

阈值越低删得越狠。**调 NMS 阈值 = 在「漏检」和「重复框」之间选**，这是检测任务最常见的调参点。

**常见误区**

- **通道顺序反了**。PyTorch 是 `[N, C, H, W]`，你熟悉的 OpenCV 是 `[H, W, C]` 且默认 **BGR**。
  从 `cv2.imread` 喂进模型前要 `transpose(2,0,1)` + `cvtColor(BGR2RGB)` + `/255`，
  这三步漏一步就是「模型什么都识别不出来」。
- **`padding` 不是可有可无**。不加 `p` 时每层掉 `k-1` 个像素，堆 10 层 3×3 图就没了 20 像素。
- **别用池化代替 stride**。两者都能降分辨率，但 `stride` 更省算力，现代网络越来越倾向于直接 stride。
- **感受野不是越大越好**。有效感受野远小于理论值，堆太多层反而让远处的信息被稀释。

**对应练习**：第 1~6 题（输出尺寸、参数量、手写 conv、depthwise、IoU、NMS）。

### 17.2 循环神经网络（RNN / LSTM / GRU）

**概念定义**：序列任务里每个位置的输出都依赖前面的输入。**RNN** 用一个**隐状态** $h_t$ 记住「到目前为止看过什么」，
每来一个新输入就更新一次。**LSTM / GRU** 在此之上加**门控**：用 0~1 的系数决定「旧记忆保留多少、新信息写入多少」。

**数学形式**

$$h_t=\tanh\big(x_tW_x+h_{t-1}W_h+b\big),\qquad y_t=h_tW_y$$

LSTM 多了一条**细胞状态** $c_t$ 和三个门（$f$ 遗忘、$i$ 输入、$o$ 输出）：

$$c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t,\qquad f_t=\sigma(\cdot)$$

关键在 $c_t$ 这条路上只有**逐元素乘**，没有矩阵连乘、没有 tanh 压缩 ——
所以梯度能沿着 $\prod f_t$ 走，而不像 RNN 那样沿 $\prod W_h$ 走。

**最小代码**

```python
def rnn_step(x, h, Wx, Wh, b):
    return np.tanh(x @ Wx + h @ Wh + b)

def lstm_step(x, h, c, p):
    z = np.concatenate([x, h]) @ p["W"] + p["b"]
    f, i, o, g = np.split(z, 4)                 # 三道门 + 候选记忆
    f, i, o = sigmoid(f), sigmoid(i), sigmoid(o)
    c = f * c + i * np.tanh(g)
    h = o * np.tanh(c)
    return h, c
```

**实测：RNN 的梯度会烂掉**

$d=16$、序列长 40、损失只取最后一步，反向传回各时刻的梯度范数：

| $W_h$ 缩放 | $t=0$ 的梯度 | $t=20$ | $t=40$（末端） | 首层/末端 |
|---|---|---|---|---|
| 0.5 | `3.042e-23` | `7.625e-12` | `4.000e+00` | **`7.6e-24`** |
| 0.9 | `2.834e-14` | `3.751e-07` | `4.000e+00` | **`7.1e-15`** |
| 1.2 | `3.905e-10` | `5.581e-05` | `4.000e+00` | **`9.8e-11`** |

最前面那几个词的梯度基本**等于 0**。这就是「RNN 记不住长依赖」的真实含义 ——
不是它不想记，是梯度回不去，前面那些时间步学不到任何东西。
注意这跟 [ch15](ch15_activation_init.md#c15-02) 的梯度消失是**同一个病**，只是连乘的是 $W_h$ 而不是权重矩阵。

**实测：LSTM 的门控就是一个可调的保留率**

细胞状态的梯度是 $\prod_t f_t$，纯看遗忘门：

| forget gate | 40 步后 $dc_T/dc_0$ |
|---|---|
| `0.9933` | **`0.7644`** |
| `0.5000` | **`0.0000`** |

$0.5^{40}\approx 9\times10^{-13}$。**门控不是在「记住」，是在「选择遗忘多慢」** ——
$f$ 接近 1 就能跨几十步传梯度，这也是 LSTM 初始化时遗忘门偏置常设正的直觉来源。

**参数量**（$d_{in}=16, d_h=32$，PyTorch 实测）：

| 单元 | 公式 | 参数量 |
|---|---|---|
| RNN | $h(in+h)+2h$ | **`1,600`** |
| GRU | $3\times[h(in+h)+2h]$ | **`4,800`** |
| LSTM | $4\times[h(in+h)+2h]$ | **`6,400`** |

LSTM 是 RNN 的 4 倍（3 个门 + 1 个候选），GRU 是 3 倍。**GRU 用 3/4 的代价买接近 LSTM 的效果**，
所以很多实时场景选 GRU。

**常见误区**

- **别把 RNN 当 CNN 堆**。堆 RNN 层数收益很小，长依赖问题不靠加深解决，靠门控或换注意力。
- **`detach` 忘了会炸显存**。训练语言模型时若把整段序列一次反传，图会一直挂着；
  按段截断（TBPTT）时必须 `h = h.detach()`。
- **LSTM 不是万能**。序列超过几百步，门控也压不住；2017 年后长序列基本都换 Transformer。
- **输入没排序 / 没 mask**。变长序列 padding 后必须 `pack_padded_sequence`，否则 pad 的位置会污染隐状态。

**对应练习**：第 7、8、9 题。

### 17.3 注意力与 Transformer（Attention and Transformer）

**概念定义**：注意力不做「滑动」也不做「循环」，它让**每个位置直接看所有位置**：
用 Query 去和所有 Key 算相似度，softmax 归一成权重，再对 Value 加权求和。
**它本质是一次可微的软检索** —— 你给它一个查询，它还你一堆按相关性加权的信息。

**数学形式**

$$\text{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

$Q\in\mathbb R^{n\times d_k}$、$K\in\mathbb R^{m\times d_k}$、$V\in\mathbb R^{m\times d_v}$。
$QK^\top$ 是 $n\times m$ 的相似度矩阵，softmax 按**行**归一化，再乘 $V$ 得到 $n\times d_v$ 的输出。

**最小代码**

```python
def attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    s = Q @ K.T / np.sqrt(d_k)              # 相似度
    if mask is not None:
        s = np.where(mask, s, -1e9)         # 因果掩码：不许看未来
    s = s - s.max(axis=-1, keepdims=True)   # 数值稳定
    a = np.exp(s) / np.exp(s).sum(axis=-1, keepdims=True)
    return a, a @ V
```

**实测：3 个 token 的注意力长什么样**

$d_k=4$，随机 $Q,K,V$，注意力矩阵每行和为 1：

```
0.2552 0.4599 0.2849
0.3204 0.3738 0.3058
0.3142 0.2799 0.4059
```

行和精确为 `1.0000`。加上**因果掩码**（第 $i$ 个位置只能看 $\le i$）后：

```
1.0000 0.0000 0.0000
0.4615 0.5385 0.0000
0.3142 0.2799 0.4059
```

上三角最大值精确为 `0`。**这就是 GPT 类模型「不能偷看未来」的实现方式**：
不是把未来遮起来，是把那些位置的分数设成 $-\infty$，softmax 后权重为 0。

**实测：为什么要除以 $\sqrt{d_k}$**

$q,k$ 各分量独立、方差 1 时，点积 $q\cdot k=\sum_{i=1}^{d_k}q_ik_i$ 的方差正好是 $d_k$，标准差 $\sqrt{d_k}$：

| $d_k$ | 原始点积 std | 缩放后 std | 原始最大值 |
|---|---|---|---|
| 8 | `2.82` | `0.997` | `10.80` |
| 64 | `8.00` | `1.000` | `28.03` |
| 256 | `16.09` | `1.006` | `44.33` |
| 1024 | `31.99` | `1.000` | `106.45` |

除以 $\sqrt{d_k}$ 后标准差**稳定在 1**。不除会怎样？softmax 立刻饱和：

| $d_k$ | 缩放：最大权重 / 熵 | 不缩放：最大权重 / 熵 |
|---|---|---|
| 8 | `0.251` / `2.672` | `0.851` / `0.760` |
| 64 | `0.201` / `2.766` | **`0.997`** / `0.024` |
| 256 | `0.163` / `2.674` | **`0.999`** / `0.007` |

$d_k=256$ 不缩放时，**99.9% 的注意力都压在一个 token 上**，梯度也基本消失。
一个 `√d_k` 的除法，决定注意力是「综合看」还是「只盯一个」。

**实测：位置编码怎么区分远近**

正弦编码 $\mathrm{PE}(pos,2i)=\sin(pos/10000^{2i/d})$。位置 0 与其他位置的余弦相似度：

| 距离 | 1 | 5 | 10 | 25 | 49 |
|---|---|---|---|---|---|
| 相似度 | `0.957` | `0.736` | `0.629` | `0.605` | `0.348` |

**距离越远越不像**，这就是模型能感知顺序的原因。注意力本身是**置换不变**的
（把 token 打乱，输出只是跟着打乱），所以位置信息必须**额外注入**，不是可选项。

**实测：多头的账**

`d_model=64, h=8` → 每头 `d_k=8`，QKV + 输出投影共 `4×64² = 16,384` 参数。
**多头不是把参数量翻 8 倍**：总维度固定，8 个头各看 8 维，最后拼回 64 维。
好处是不同头可以学不同的关系（一个看语法、一个看指代）。

**实测：注意力的代价是 $O(n^2)$**

`batch=1, h=8, d_model=512`：

| 序列长度 $n$ | 注意力分数个数 | CPU 一次前向 |
|---|---|---|
| 128 | `131,072` | — |
| 512 | `2,097,152` | — |
| 2048 | **`33,554,432`** | `122.8 ms` |

长度翻 4 倍，分数翻 16 倍。**这就是长上下文贵的根本原因**，也是 FlashAttention / 稀疏注意力要解决的问题。

**常见误区**

- **别把注意力图当解释**。权重高只代表「这一步加权多」，不代表因果重要性；很多工作证明两者经常不一致。
- **别忘了位置编码**。去掉它，模型对「狗咬人」和「人咬狗」完全一样。
- **多头 ≠ 复制 8 份**。每个头维度是 $d_{model}/h$，不是 $d_{model}$。
- **`mask` 要用 `-inf` 不是 `0`**。填 0 会让被遮的位置拿到 $\exp(0)=1$ 的权重，等于没遮。

**对应练习**：第 10~14 题。

### 17.4 三条路线怎么选（Inductive Bias）

**概念定义**：**归纳偏置**是模型「天生相信什么」。数据少的时候，偏置对了就省样本；
数据多了，偏置反而成了限制。三条路线的偏置完全不同：

| | CNN | RNN | Transformer |
|---|---|---|---|
| 天生相信 | 局部、平移不变 | 顺序、状态递推 | 任意位置可互相关注 |
| 参数随长度增长 | 否（核共享） | 否（循环共享） | 否，但**计算量** $O(n^2)$ |
| 长依赖 | 靠堆层 / 空洞卷积 | 靠门控，>200 步就吃力 | **原生支持** |
| 并行性 | 好 | **差**（必须按时间步串行） | 好（训练时全并行） |
| 典型场景 | 图像、检测、分割 | 小序列、传感器、实时 | 语言、长文档、多模态 |

**判据（按顺序问自己）**

1. **输入有没有明显的空间/时间局部结构？** 有 → CNN（图像、语音频谱）最省样本。
2. **序列短、要低延迟、算力受限？** → GRU / LSTM 仍然划算，别硬上 Transformer。
3. **需要长距离对齐、或要并行训练大模型？** → Transformer。
4. **数据很少（几百张图）？** → 别从头训，用预训练骨干 + 微调（见 [第 6 篇](../../05_llm/README.md)）。

**和你已有经验的衔接**

- **视觉组**：检测头输出「框 + 分数」，后处理就是本章 17.1 的 IoU + NMS。这块你在 RM 里已经摸过，
  现在知道它为什么必须存在（一个目标会被预测出几十个框）。
- **以图搜图（[实践终点](../../06_engineering/README.md)）**：CNN 骨干把图片压成一个 embedding 向量，
  后面接 [ch12 的降维](../../03_unsupervised/docs/ch12_dimensionality.md#c12-04)和向量检索。
  ViT（纯 Transformer 做图像）也能干这活，但小数据上 CNN 的归纳偏置更省样本。
- **OpenCV 的 `filter2D`** 就是 17.1 的卷积，只是它默认做相关而不是严格卷积（不翻转核）——
  对学习到的权重没区别，因为翻转与否可以由训练自己吸收。

**常见误区**

- **别默认「新架构一定更好」**。表格数据上 Transformer 经常打不过梯度提升（[ch09](../../02_supervised/docs/ch09_ensemble.md)）。
- **别在小数据上从头训 Transformer**。它没有局部性先验，需要大量数据才学得会「邻近像素相关」。
- **别忽视推理成本**。$O(n^2)$ 在小 $n$ 时无所谓，$n=2048$ 就是 `122.8 ms`（CPU）。
- **别把三条路线当互斥**。ConvNeXt、Conformer、ViT + 卷积 stem 都是混着用的。

**对应练习**：第 15 题。

## 小结：一张选型表

| 你的输入 | 首选 | 关键超参 | 常见坑 |
|---|---|---|---|
| 图像 / 视频帧 | CNN（ResNet / MobileNet） | 核大小、stride、通道数 | 通道顺序、归一化 |
| 短序列 / 传感器 | GRU / LSTM | 隐层维度、层数 | 忘了 detach、没 mask |
| 长文本 / 多模态 | Transformer | `d_model`、头数、层数 | 漏位置编码、mask 填 0 |
| 检测框后处理 | IoU + NMS | NMS 阈值 | 阈值太低漏检 |
