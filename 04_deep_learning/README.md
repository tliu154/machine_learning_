## 和 C++ / OpenCV 经验的衔接

- Tensor ≈ 带 autograd 的 ndarray，形状约定 `[N, C, H, W]`（注意和 numpy 图像的 `[H, W, C]` 不同）
- 图像预处理：BGR↔RGB、归一化、resize，这些你已经会，重点讲**为什么框架要这么规定**
- 部署阶段回到 C++/OpenVINO，是已有优势能直接迁移的地方
