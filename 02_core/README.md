## 贯穿全模块的三个问题

1. 这个指标在**业务上**意味着什么？（准确率为何在类别不平衡时会骗人）
2. 测试集有没有被**间接看到**？（缩放/编码必须在划分之后 fit）
3. 换一批数据还能这么好吗？（交叉验证与置信区间）
