## 为什么这篇最重要

算法会过时，评估与泛化的判断力不会。四个章一条线：

```
是什么（ch03）→ 怎么训练（ch04）→ 为什么出错（ch05）→ 怎么量化好坏（ch06）
```

其中 **ch04 训练三步骤**（模型 → 损失 → 优化 → 训练循环）是这次大纲调整补进来的关键一章：
后面所有算法、所有网络，本质都是这三步换个 `f` 和换个 `L`。

## 贯穿全篇的三个问题

1. 这个指标在**业务上**意味着什么？（类别不平衡时准确率为什么骗人）
2. 测试集有没有被**间接看到**？（缩放/编码必须在划分之后 fit）
3. 换一批数据还能这么好吗？（交叉验证、分布漂移）
