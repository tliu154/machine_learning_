# 第 3 章 机器学习是什么（What is Machine Learning）

> 前置：第 1 篇（numpy 数组与广播） ｜ 对应练习：[`ch03_ex.py`](../exercises/ch03_ex.py)

**一句话**：C++ 里你把规则写进 `if/else`，机器学习里规则是**从数据里算出来的参数**。
判断「这是不是 ML」只看一件事 —— 判定规则是人写死的，还是样本学出来的。

> 第 2 篇四章一条线：是什么（本章）→ 怎么训练（[ch04](ch04_training_steps.md)）→
> 为什么出错（[ch05](ch05_error_sources.md)）→ 怎么量化好坏（[ch06](ch06_evaluation_metrics.md)）。

### 先看结论：同一条判定规则，写死 vs. 学出来

真实边界 $x^*=0.62$，200 个带 5% 标签噪声的训练样本，4000 个独立测试点，全部实跑：

| 做法 | 规则从哪来 | test acc |
|---|---|---|
| 手写 `if x > 0.5` | 人猜的 | 0.8778 |
| 从数据学阈值 **0.6133** | 数据算的 | **0.9922** |
| 边界漂移到 0.80 后，死守手写 0.5 | 不会变 | 0.6973 |
| 边界漂移后沿用旧规则 0.6133 | 数据算的，但过期了 | 0.8157 |
| 用新数据重新学（得 **0.7991**） | 数据算的，重跑一遍 | **0.9995** |

关键不在「谁分得准」，在**规则能不能重新算出来**。

### 3.1 定义：什么叫「学」（What is Learning）

**概念定义**：经典定义是「对某类任务 $T$ 和性能度量 $P$，程序利用经验 $E$ 使 $T$ 上的 $P$ 变好，就叫学习」。
拆成三件套 —— **$E$ 是数据、$T$ 是要做的事、$P$ 是怎么算好坏**。三者缺一个，「学习」就说不清。
[ch04](ch04_training_steps.md) 的训练三步骤（模型 → 损失 → 优化）就是给这三件套配实现：
损失对应 $P$，数据对应 $E$，模型对应 $T$ 的候选解。

**数学形式**：

$$\hat{y} = f_{\theta}(x),\qquad \theta^* = \underset{\theta}{\arg\min}\ \frac{1}{n}\sum_{i=1}^{n}\ell\big(f_\theta(x_i),\, y_i\big)$$

「$\theta$ 是规则的数值参数，$\ell$ 是错了罚多少；学习就是解这个最小化」。
和 C++ 的本质差别：$\theta$ **不是源码里的常量**，是运行时由数据算出来的。
numpy：`cand` 里挑训练误差最小的那个，就是一次最朴素的 $\arg\min$。

**最小代码**（一维阈值分类，全章共用）：

```python
import numpy as np

rng = np.random.default_rng(42)
x_tr = rng.uniform(0, 1, 200)
y_tr = (x_tr > 0.62).astype(int)
y_tr[rng.choice(200, 10, replace=False)] ^= 1     # 5% 标签噪声

def learn_threshold(x, y):
    xs = np.sort(np.unique(x))
    cand = (xs[:-1] + xs[1:]) / 2                 # 候选阈值：相邻取值的中点
    pred = x[:, None] > cand[None, :]             # (n, m) 一次算完所有候选
    err = (pred != y[:, None]).mean(axis=0)
    return float(cand[np.argmin(err)])

t = learn_threshold(x_tr, y_tr)                   # 0.6133
```

这里没有梯度、没有迭代，只有一次穷举 —— 但它已经是完整的学习：
**模型**是 $x>t$、**损失**是 0-1 错误率、**优化**是扫候选取最小。ch04 只是把这三步换成可导版本。

**泛化**：学出来的东西要在**没见过的数据**上成立。训练集 acc 0.95（5% 噪声），
测试集 0.9922 —— 这里测试反而更高只是因为测试集没加噪声；两者有差距才是常态，
这件事从 [ch05](ch05_error_sources.md) 起会一直纠缠我们。

**常见误区**：**「代码里出现 `if/else` 就不算机器学习」是错的**。
决策树整棵树都是 `if/else`（[ch08](../../02_supervised/docs/ch08_classical_classifiers.md)），
但每个切分点和阈值都是学出来的。**判据是规则参数的来源，不是控制流长什么样**。

**对应练习**：[第 1、2 题](../exercises/ch03_ex.py)

> 和 C++ 的差异：C++ 里 `const double THRESHOLD = 0.5;` 写在源码里，改规则要改代码、重新编译。
> ML 里规则的数值在**数据文件**里，代码一行不动，换数据重新 `fit` 就更新了。
> 这是本章最值得带走的一个视角切换。

### 3.2 学习范式：标签从哪来（Learning Paradigms）

**概念定义**：范式由「**有没有 $y$、$y$ 从哪来**」决定，不由模型结构决定。同一个 `f_theta` 换个数据来源就是另一种范式。

| 范式 | 拿到什么 | 优化什么 | 本套笔记在哪 |
|---|---|---|---|
| 监督 | $(x_i, y_i)$ | $\sum \ell(f(x_i), y_i)$ | ch04 起全部 |
| 无监督 | 只有 $x_i$ | 结构 / 密度 / 重构误差 | ch11~ch13 |
| 半监督 | 少量 $y$ + 大量无标签 $x$ | 两者混合 | 本节演示 |
| 自监督 | 只有 $x$，**自己造伪标签** $\tilde y=g(x)$ | $\sum \ell(f(x'), \tilde y)$ | ch18 LLM 预训练 |
| 强化 | 状态 + 动作 + 奖励（延迟、稀疏） | 累积回报 | 本教程不展开 |

**数学形式**：监督与自监督只差 $\tilde y$ 的来源 ——
$\min_\theta \frac{1}{n}\sum \ell(f_\theta(x_i), y_i)$ 里，$y_i$ 是人工标注还是 $g(x_i)$ 自动构造。
「自」字的意思就是**标签不需要人给**。

**最小代码**（三个范式各 4 行）：

```python
# ① 自监督：把序列错开一位，用「预测下一个值」造伪标签
T = 500
s = np.zeros(T)
for i in range(1, T):
    s[i] = 0.6 * s[i-1] + rng.normal(0, 0.2)
A = np.column_stack([s[:-1], np.ones(T-1)])       # 输入 = 上一时刻
y_tilde = s[1:]                                  # 伪标签 = 下一时刻
a_hat, b_hat = np.linalg.lstsq(A, y_tilde, rcond=None)[0]
print(a_hat, b_hat)                              # 0.6020, 0.0051（真值 a=0.6）
```

全程没有一个人工标签，却把生成规律学回来了 —— 这就是「下一个 token 预测」的最小原型。

```python
# ② 无监督：只有 X，找两个簇中心（ch11 正式讲，这里只看「没标签也能分组」）
def two_means(X, iters=20, seed=0):
    g = np.random.default_rng(seed)
    c = X[g.choice(len(X), 2, replace=False)].copy()
    for _ in range(iters):
        lab = np.argmin(((X[:, None, :] - c[None, :, :]) ** 2).sum(2), axis=1)
        for k in range(2):
            if np.any(lab == k):
                c[k] = X[lab == k].mean(0)
    return c, lab
```

实测两簇高斯点（中心 $\pm 1$、标准差 0.4），学得中心 `[[1.001, 0.967], [-1.018, -0.952]]`。
训练时**完全没看标签**；事后才用标签评估，把簇映射成类别的最好准确率是 **1.000**
（这两簇分得太开，真实数据不会这么干净，别拿这个数当预期）。

```python
# ③ 半监督：10 个真标签 → 给其余样本打伪标签 → 再学一次
small = rng.choice(200, 10, replace=False)
t_10 = learn_threshold(x_tr[small], y_tr[small])         # 0.5388
pseudo = (x_tr > t_10).astype(int)                        # 伪标签
t_self = learn_threshold(x_tr, pseudo)                    # 0.5371
```

实测：只用 10 个标签 → test acc **0.9187**；伪标签自训练后 → **0.9170**（**没涨，还略降**）；
用全部 200 个真标签 → **0.9922**。

**常见误区**：**半监督自训练不是白捡标签**。
伪标签只是把模型自己的预测抄了一遍，没带来新信息，所以阈值从 0.5388 挪到 0.5371 几乎没动。
它真能生效需要额外前提（聚类假设 / 低密度分离）、置信度筛选、别把错伪标签反复自我强化。
同理，**无监督聚类后按多数投票贴标签，不等于模型学到了类别语义** —— 标签只在评估时用了一次。
强化学习也要区分：它的反馈是「环境给的延迟奖励」，不是数据集里的一列 $y$。

### 3.3 任务类型：看 $y$ 长什么样（Task Types）

**概念定义**：任务类型由**输出空间**决定，跟模型内部长什么样无关。

| 任务 | $y$ 的样子 | 例子 | 指标 |
|---|---|---|---|
| 分类 | 有限离散集合 | 是不是垃圾邮件、哪个数字 | Accuracy / F1 / AUC（[ch06](ch06_evaluation_metrics.md)） |
| 回归 | 连续实数 | 房价、温度、下一时刻的值 | MAE / RMSE / R² |
| 结构化学习 | 序列 / 树 / 图 | 翻译、句法树、分子式 | 序列级准确率、BLEU |

**数学形式**：$\mathcal{Y}$ 有限 $\Rightarrow$ 分类；$\mathcal{Y}\subseteq\mathbb{R}\Rightarrow$ 回归；
$\mathcal{Y}$ 是组合结构 $\Rightarrow$ 结构化学习。注意「结构化」的难点是**输出各部分的联合约束**
（一句话里主谓要一致），不是单纯多预测几个数。

**最小代码**：

```python
def task_type(y):
    y = np.asarray(y)
    # 唯一值很少，或取值全是整数 → 分类；否则回归
    if len(np.unique(y)) <= max(10, 0.05 * len(y)) or np.all(y == y.astype(int)):
        return "classification"
    return "regression"

y_cls = (x_tr > 0.62).astype(int)      # 分类
y_reg = np.sin(2 * np.pi * x_tr)       # 回归：同一个 x，换个 y 就换任务
```

**常见误区**：**逻辑回归是分类算法**，名字里的「回归」指它内部对 log-odds 做线性回归
（[ch07](../../02_supervised/docs/ch07_linear_models.md)）。**别按模型名字判断任务类型，按 $y$ 判断**。
还有：把连续 $y$ 阈值化成 0/1 就变成分类，信息会丢 —— 除非业务本来就要一个决策。

**对应练习**：[第 7 题](../exercises/ch03_ex.py)

### 3.4 传统编程 vs. 机器学习（Rule-based vs. Learned）

**概念定义**：两者都能把输入变成输出，差别在**规则由谁提供、怎么更新**。

| | 传统编程 | 机器学习 |
|---|---|---|
| 规则来源 | 人把领域知识写成 `if/else` | 数据里解出 $\theta$ |
| 改动成本 | 改源码 → 重新编译 / 发布 | 换数据 → 重新 `fit`，代码不动 |
| 失效方式 | 规则过时、边界情况写不全 | 分布漂移、数据有偏、过拟合 |
| 可解释性 | 每一步都可逐行审计 | 常是黑盒（ch22 专题） |
| 需要什么 | 明确且稳定的规则 | 足够且有代表性的样本 |

**分布漂移实测**（承接开头那张表）：真实边界从 0.62 变到 0.80 之后，
手写规则直接掉到 **0.6973**，旧学到的规则掉到 **0.8157**，
而拿新数据重学得 0.7991、恢复到 **0.9995**。
注意 **ML 不会自己变好** —— 变好是因为有人重新跑了一次 `fit`。
真要「自动」，得有第 7 篇 ch21 的漂移监控 + 重训流水线。

**什么时候别用 ML**（比「怎么用」更该先问）：

- 规则明确、稳定、要 100% 确定：税率计算、协议解析、排序算法
- 没有数据，或数据有系统性偏差且无法修正
- 需要给出可审计的逐步证明（法律裁定、安全联锁）
- 错误代价极高且无法容错，而规则可以穷举

**常见误区**：**别把「能适应变化」当成模型自带的能力**。
模型是一堆冻结的参数；适应能力来自**重新训练的流程**，不在模型里。
另一个坑：数据里没有的规则，模型学不出来 —— 训练集只覆盖 $x<0.6$ 时，
[ch05 5.6](ch05_error_sources.md) 会实测外推能崩到什么程度。

**对应练习**：[第 3 题（漂移前后对比）](../exercises/ch03_ex.py)

> 和 C++ 的差异：你有 OpenCV/RoboMaster 视觉组背景，对「手调阈值 + 形态学滤波」这套流水线应该很熟
> —— 那正是传统编程一侧。机器学习不是把它推翻，是把**阈值、权重这些手调的常量**换成从样本里解出来的参数。
> 预处理、几何约束这些先验照样有用（[ch10](../../02_supervised/docs/ch10_feature_engineering.md)）。

## 小结

| C++ / 已有认知 | 本章写法 |
|---|---|
| 规则是源码里的常量 | 规则是数据算出来的参数 $\theta$ |
| `if/else` 是手写逻辑 | 决策树也是 `if/else`，但切分点是学出来的 |
| 改行为 = 改代码重编译 | 改行为 = 换数据重新 `fit` |
| 标签只能人工标 | 自监督从数据自己造伪标签 |
| 程序对不对看能不能跑通 | 模型好不好看**没见过的数据**（泛化） |

> **最容易踩的 3 个坑**：
> 1. 以为「有 `if/else` 就不是 ML」—— 判据是参数来源，不是控制流
> 2. 以为伪标签自训练白捡标注 —— 实测 acc 从 0.9187 反而降到 0.9170
> 3. 以为分布漂移后模型会自己适应 —— 它只是等着重跑一次 `fit`

**一条判据带走**：指着系统里那个决定输出的数值问一句 —— **它写在代码里，还是从样本里算出来的？**
