## 每章固定结构

1. 直觉：它把数据想成什么
2. 数学：一行核心公式，不堆推导
3. sklearn：三行跑通（`fit` / `predict` / `score`）
4. 手写：numpy 复现关键一步
5. **失效场景**：什么数据上会翻车
6. 小结表 + 练习
