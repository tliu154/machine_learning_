## 定位与边界

- 讲**怎么用、为什么这么设计、怎么评估**，不讲「如何训练一个大模型」
  （个人项目没有那个算力，硬写只会变成抄论文摘要）
- ch18 是理解层：自监督 → 预训练 → 微调，把「表征学习」讲清楚
- ch19 是应用层：Prompt / RAG / Agent / 评估，每一节都配能本地跑的最小例子

## 练习设计方向

- ch18：在小语料上手写一个 masked token 预测任务；对比「冻结特征」与「微调」的效果
- ch19：搭一个最小 RAG（几段文本 + 向量检索 + 生成），**故意制造一次幻觉并分析原因**；
  设计一组能区分好坏回答的评估 rubric
