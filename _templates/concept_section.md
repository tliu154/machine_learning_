### 7.1 线性回归（Linear Regression）

**概念定义**：用输入特征的线性组合去预测一个连续值，即「找一条最贴合数据的直线」。
它同时是后面逻辑回归、神经网络全连接层的共同骨架。

**数学形式**：
$$\hat{y} = \mathbf{w}^{\top}\mathbf{x} + b,\qquad
L(\mathbf{w}, b) = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

第一式是模型，第二式是「所有样本预测误差平方的平均值」（MSE）。
numpy：`np.mean((y - X @ w - b) ** 2)`。

**最小代码**：
```python
import numpy as np

rng = np.random.default_rng(42)          # 固定种子，可复现
X = rng.random((100, 1)) * 10
y = 3 * X.ravel() + 2 + rng.normal(0, 0.5, 100)

w, b = np.linalg.lstsq(
    np.column_stack([X, np.ones(len(X))]), y, rcond=None
)[0]
print(w, b)                              # 约 3.0, 2.0
```

**常见误区**：**别手写 `np.linalg.inv(A.T @ A)` 求正规方程**。
特征共线或 $d>n$ 时该矩阵奇异，`lstsq` 走 SVD 才能给出数值稳定的最小范数解。

**对应练习**：[`ch07_ex.py` 第 1 题](../exercises/ch07_ex.py)

> 和 C++ / 已有认知的差异：C++ 里要手写双重循环累加 $\sum$，
> numpy 里 `@` 一次做完；代价是形状错了不会编译报错，只在运行时炸。
