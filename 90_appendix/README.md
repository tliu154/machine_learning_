- **A 术语表**：中英对照 + 一句话直觉，别抄维基定义。易混词以 [NOTATION.md](../NOTATION.md) 为准，不重复维护

- **C 模板**：训练循环 / 评估 / 画图三块，可直接复制
- **D 数据集**：注明下载方式、许可、大小；**仓库内不放数据**
- **E 练习索引**：**只放链接，不重复存答案** —— 答案统一在各 `chNN_ex.py` 的 `# region 参考答案` 里
